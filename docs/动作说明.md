# 动作与状态说明

## 标准 Codex v2 图集

图集共 8 列×11 行；每格 192×208 像素。

| 行 | 标准状态 | 使用帧 |
| --- | --- | --- |
| R0 | idle | C0–C5 |
| R1 | running-right | C0–C7 |
| R2 | running-left | C0–C7 |
| R3 | waving | C0–C3 |
| R4 | jumping | C0–C4 |
| R5 | failed | C0–C7 |
| R6 | waiting / needs input | C0–C5 |
| R7 | running | C0–C5 |
| R8 | review / ready | C0–C5 |
| R9 | look directions 000°–157.5° | C0–C7 |
| R10 | look directions 180°–337.5° | C0–C7 |

R9 与 R10 合计 16 个顺时针方向帧，000° 表示向上看。

## 小蕾米维护者机器上的实验映射

维护者曾按视觉内容提出以下细分目标：

| 任务阶段 | 目标帧 |
| --- | --- |
| 思考 | R7 C0–C2 |
| 工具执行 | R7 C3–C5、R8 C0 |
| 文字输出 | R6 C0–C5 |
| 任务完成 | R7 C1–C5 |

这套细分并不是 `pet.json` 的标准字段。它需要客户端运行时能区分“推理、工具调用、输出、完成”等更细事件，因此不随本仓库自动安装，也不能保证跨客户端版本工作。

仓库刻意不包含修改后的应用程序 bundle、ASAR 或反编译代码。这样可以避免覆盖官方客户端、降低升级和稳定性风险，并让 pet 素材本身保持可移植。
