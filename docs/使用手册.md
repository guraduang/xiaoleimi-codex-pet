# 小蕾米使用手册

## 1. 环境要求

- 支持 Pets 的 ChatGPT 桌面端，或支持图形 pet 的 Codex CLI。
- 安装包中的 `pet.json` 与 `spritesheet.webp` 必须放在同一个目录。
- 若系统启用了“减少动态效果/Reduced Motion”，pet 会显示静态帧而不是完整动画。

## 2. Linux/macOS 安装

### 自动安装

```bash
git clone https://github.com/guraduang/xiaoleimi-codex-pet.git
cd xiaoleimi-codex-pet
./install.sh
```

脚本默认安装到：

```text
${CODEX_HOME:-$HOME/.codex}/pets/xiaoleimi/
```

如果目标目录中已有同名 pet，脚本会覆盖 `pet.json` 和 `spritesheet.webp`，不会删除其他目录。

### 手动安装

```bash
PET_DIR="${CODEX_HOME:-$HOME/.codex}/pets/xiaoleimi"
mkdir -p "$PET_DIR"
cp pet.json spritesheet.webp "$PET_DIR/"
```

## 3. Windows PowerShell 安装

在仓库目录中运行：

```powershell
$CodexHome = if ($env:CODEX_HOME) { $env:CODEX_HOME } else { Join-Path $HOME ".codex" }
$PetDir = Join-Path $CodexHome "pets\xiaoleimi"
New-Item -ItemType Directory -Force -Path $PetDir | Out-Null
Copy-Item .\pet.json, .\spritesheet.webp -Destination $PetDir -Force
```

## 4. 在桌面端启用

1. 打开 ChatGPT 桌面端。
2. 打开底部个人资料菜单，选择“Pets”；也可以进入“设置 → Pets”。
3. 点击“Refresh/刷新”。
4. 选择“小蕾米”。
5. 在对话中输入 `/pet`，或从命令菜单选择“Wake Pet”。

再次输入 `/pet`，或选择“Tuck Away Pet”，可收起桌宠。桌宠位置和选择通常会在重新打开应用后保留。

## 5. Codex CLI 中启用

在交互式 Codex CLI 中：

```text
/pets
/pets 小蕾米
/pets off
```

CLI 图形 pet 需要 iTerm2 3.6+，或支持 Kitty graphics/Sixel 的终端；tmux 和 Zellij 中不可用。

## 6. 更新

拉取新版并重新运行安装脚本：

```bash
git pull --ff-only
./install.sh
```

然后在“设置 → Pets”中点击“Refresh/刷新”。通常不需要修改应用程序安装目录。

## 7. 卸载

先在“设置 → Pets”切换到其他 pet，再删除：

```bash
rm -rf "${CODEX_HOME:-$HOME/.codex}/pets/xiaoleimi"
```

删除前请核对路径必须以 `/pets/xiaoleimi` 结尾。Windows 可删除 `%USERPROFILE%\.codex\pets\xiaoleimi`，或 `CODEX_HOME` 下对应目录。

## 8. 常见问题

### 刷新后看不到小蕾米

- 确认目录名为 `xiaoleimi`，不要写成 `xioalemi` 或其他拼写。
- 确认目录中同时存在 `pet.json` 和 `spritesheet.webp`。
- 确认 `pet.json` 中 `id` 为 `xiaoleimi`、`spriteVersionNumber` 为 `2`。
- 完全退出并重新打开桌面端后，再进入 Pets 页面刷新。重启前先保存正在执行的任务。

### 只显示静态图片

检查操作系统是否启用了“减少动态效果/Reduced Motion”。开启后，Pets 会按设计使用静态帧。

### 动作与预期状态不一致

Pet 图集只提供动作素材；某一时刻播放哪一行动作，由客户端状态映射决定。不同客户端版本可能调整状态事件和优先级。本仓库不修改客户端运行时代码。

### 多个任务同时运行时动作不对应当前页面

桌面 pet 会综合多个对话的活动，优先级通常为：需要输入、阻塞、已完成未读、运行中。打开 pet 的活动托盘可以选择对应任务。

## 9. 安全说明

- 不要用来源不明的脚本覆盖 ChatGPT/Codex 安装目录。
- 本仓库无需替换 `app.asar` 或其他应用程序文件。
- 更新前可以用 `sha256sum -c SHA256SUMS` 校验发布文件。
