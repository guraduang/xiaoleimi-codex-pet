# 跨机器迁移指南

> 2026-09-09 更新：当前新增 Linux `26.901.20858` 适配。下文涉及 `26.814.41407` 的模块名、哈希和三模块变换属于历史基线；当前适配范围、安装/回滚流程及验收状态以[跨版本维护方案](跨版本维护方案.md)为准。

## 1. 先确认你需要哪一种安装

### 仅安装角色素材

适合希望使用官方 Running、Needs input、Ready、Blocked 映射的情况：

```bash
git clone https://github.com/guraduang/xiaoleimi-codex-pet.git
cd xiaoleimi-codex-pet
./install.sh
```

### 安装素材和细分动作映射

目前只支持 Linux ChatGPT/Codex desktop `26.814.41407`：

1. 保存所有任务。
2. 正常退出 ChatGPT/Codex。
3. 运行：

```bash
./install-with-runtime.sh
```

脚本会依次执行：

1. 定位 `app.asar`。
2. 检查版本和三个目标模块的官方 SHA-256。
3. 安装 `xiaoleimi` Pet 包。
4. 把官方原始 ASAR 备份到 `${CODEX_HOME:-$HOME/.codex}/pet-runtime-backups/`。
5. 在临时目录生成补丁结果并重新检查三个模块。
6. 仅在验证通过后，用一次原子式安装替换目标文件。
7. 保持应用关闭，等待你自行启动。

如果应用安装在其他位置：

```bash
CHATGPT_ASAR_PATH=/absolute/path/to/resources/app.asar ./install-with-runtime.sh
```

也可以把 ASAR 路径作为第一个参数：

```bash
./install-with-runtime.sh /absolute/path/to/resources/app.asar
```

写入系统安装目录时，脚本会调用 `sudo`。它不会保存或上传密码。

## 2. 安装后验证

启动应用前可以验证文件层：

```bash
./scripts/verify-install.sh
```

输出中的运行时状态应为：

```text
"status": "patched"
```

启动应用后：

1. 打开“Settings → Pets”。
2. 点击“Refresh”。
3. 选择“小蕾米”。
4. 输入 `/pet` 唤醒。
5. 分别观察普通推理、工具调用、文字输出、完成未读和需要输入。

文件验证只能证明补丁、资源和状态通路已经安装；最后一步显示层验收仍必须在目标机器上实际触发这些事件。

## 3. 出现 unsupported-or-mixed

这表示另一台机器不是已经验证的官方原始版本，或者曾被其他补丁修改。工具会在写入前停止。

运行只读检查：

```bash
node scripts/runtime-patch.js inspect /absolute/path/to/resources/app.asar
```

请保留输出中的以下信息：

- `appVersion`
- `status`
- 三个 chunk 的 `path`、`size` 和 `sha256`

不要上传完整 `app.asar`、账号配置、日志或整个 `.codex` 目录。要支持新版本，应基于该版本的官方原始安装单独增加适配器并重新完成显示层验证。

## 4. 回滚

先正常退出 ChatGPT/Codex，然后显式传入安装时生成的备份：

```bash
./scripts/restore-runtime.sh \
  "$HOME/.codex/pet-runtime-backups/app.asar.26.814.41407.<原始SHA256>"
```

如果安装路径不是默认位置：

```bash
./scripts/restore-runtime.sh /path/to/backup.asar /path/to/installed/app.asar
```

恢复脚本会先验证备份是受支持的官方原始版本，也不会替你启动或重启应用。

## 5. 更新客户端时

1. 先允许官方更新覆盖旧运行时补丁。
2. 重新运行 `runtime-patch.js inspect`。
3. 只有状态为 `official-supported` 时才能再次安装运行时映射。
4. 如果显示 `unsupported-or-mixed`，不要强行套用旧补丁。

Pet 素材本身可继续通过 `./install.sh` 更新，不依赖运行时补丁。
